# ShulkerCore Bot

Discord bot สำหรับ Minecraft account market (mc-market-bot)

## Setup

```bash
npm install
cp .env.example .env
# แก้ค่าใน .env ให้เป็นของจริง
npm run deploy   # deploy slash commands
npm start        # รันบอท
```

## Environment Variables

ดู `.env.example` — ต้องตั้งค่า TOKEN, CLIENT_ID, GUILD_ID, CATEGORY_ID, DONUT_API_KEY
